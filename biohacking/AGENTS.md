# Biohacking Ledger Agent Instructions

- Treat `log.md` as the authoritative record of what the user changed and observed.
- Never invent missing measurements, dates, exposures, symptoms, or context.
- Keep observations separate from causal interpretations.
- Maintain the current hypothesis, contrary evidence, confidence, and smallest useful next test in `analysis.md`.
- Prefer tests that vary one main factor at a time when practical.
- Treat mechanisms and diagnoses as unconfirmed unless supported by appropriate evidence.
- Keep recommendations proportional to the amount and quality of evidence.
- Preserve historical log entries. Correct a material transcription error only when the correction is explicit.
- Keep the system small. Add structure only after repeated friction or a demonstrated analysis need.
